# aqicn daily CSV export checklist

One-time export of daily history (1 July 2026 to today) used to train and backtest the daily model.

For each station: open the link, click **Download this data (CSV format)**, accept aqicn's terms, and save the file as `<DOE id>.csv`
(for example `CA22W.csv`) into `data/raw/aqicn_daily/`. That folder is git-ignored: aqicn's terms forbid redistributing archived data, so these files never go public.

63 stations. Tick each one off as you go.
